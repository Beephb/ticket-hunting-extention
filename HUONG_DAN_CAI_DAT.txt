  SĂN VÉ PRO v2.0 — HƯỚNG DẪN CÀI ĐẶT
════════════════════════════════════════════════════════════════════

Yêu cầu:
  - Windows 10 / 11 (64-bit)
  - Google Chrome
  - Tài khoản Ticketbox và/hoặc 1Zone (đã đăng nhập trên Chrome)


────────────────────────────────────────────────────────────────────
BƯỚC 1: GIẢI NÉN FILE
────────────────────────────────────────────────────────────────────

  1. Chuột phải vào file "SanVePro-v2.0.zip" → "Extract All..."
  2. Chọn nơi giải nén (vd: Desktop, hoặc D:\SanVePro)
  3. Sau khi xong sẽ có 2 thứ trong folder:
       - SanVePro.exe        (ứng dụng desktop)
       - extension\          (folder để load vào Chrome)


────────────────────────────────────────────────────────────────────
BƯỚC 2: CHẠY ỨNG DỤNG DESKTOP
────────────────────────────────────────────────────────────────────

  1. Double-click vào file "SanVePro.exe"

  2. Nếu Windows hiện cảnh báo "Windows protected your PC":
       - Bấm "More info" (thêm thông tin)
       - Bấm "Run anyway" (chạy ngay)
     (Cảnh báo này là vì .exe chưa có chứng chỉ. Tool an toàn.)

  3. Một cửa sổ ứng dụng sẽ mở ra, hiển thị:
       ✅ API sẵn sàng tại port 9279
       📌 Load extension vào Chrome, extension sẽ tự kết nối.

  KHÔNG đóng cửa sổ này khi sử dụng tool.


────────────────────────────────────────────────────────────────────
BƯỚC 3: CÀI EXTENSION VÀO CHROME
────────────────────────────────────────────────────────────────────

  1. Mở Chrome
  2. Gõ vào thanh địa chỉ:  chrome://extensions/
  3. Bật công tắc "Developer mode" (góc trên bên phải)
  4. Bấm nút "Load unpacked" (góc trên bên trái)
  5. Chọn folder "extension" (trong folder vừa giải nén ở Bước 1)
  6. Extension "Săn Vé Pro" xuất hiện trong danh sách
  7. Bấm icon ghim (pin) cạnh thanh địa chỉ để dễ thấy icon extension


────────────────────────────────────────────────────────────────────
BƯỚC 4: CẤU HÌNH
────────────────────────────────────────────────────────────────────

  Trong ứng dụng desktop (SanVePro.exe):

  TAB "Thông Tin" — điền 1 lần:
    - Họ tên
    - Số điện thoại
    - Email
    - Địa chỉ (chỉ cần cho 1Zone)

  TAB "Chọn Vé":
    - Nền tảng:      1Zone   hoặc   Ticketbox
    - Kiểu chọn ghế: Chọn zone (khu)   hoặc   Chọn ghế cụ thể
    - Ưu tiên:       điền tên khu / hàng / ghế muốn mua
    - Số lượng vé:   1, 2, 3...
    - ✅ Tick "Bật bot tự động"

  Bấm "💾 Lưu config" sau khi điền xong.


────────────────────────────────────────────────────────────────────
BƯỚC 5: SĂN VÉ
────────────────────────────────────────────────────────────────────

  1. Đăng nhập tài khoản Ticketbox/1Zone trên Chrome (nếu chưa)
  2. Với Ticketbox: vào event, click 1 khu bất kỳ và giải captcha 1 lần
     (token captcha sẽ được lưu cache 1 giờ, không cần giải lại)
  3. Mở tab sự kiện cần săn vé
  4. Bấm phím tắt:

       Alt + 1   →  Săn vé + tự chọn ghế + điền form (FULL AUTO)
       Alt + 2   →  Chỉ chọn ghế (khi đang ở trang chọn vé)
       Alt + 3   →  Chỉ điền form checkout

  5. Khi bot reserve thành công, ứng dụng desktop sẽ hiển thị:
       - Mã đặt vé (bookingCode / orderId) → có thể copy
       - Đếm ngược thời gian còn lại để thanh toán
       - Nút "🌐 Mở checkout" → mở trang thanh toán

  6. Bot KHÔNG tự động thanh toán. Bạn phải tự bấm thanh toán.


────────────────────────────────────────────────────────────────────
LƯU Ý QUAN TRỌNG
────────────────────────────────────────────────────────────────────

  • LUÔN MỞ SanVePro.exe trước khi dùng tool. Extension cần kết nối
    với app desktop để lấy config + ghi log.

  • Với Ticketbox: phải SOLVE CAPTCHA bằng tay 1 lần cho mỗi suất
    diễn. Sau đó bot sẽ tự dùng được token cache trong 1 giờ.

  • Với 1Zone: phải đăng nhập + mở tab booking trước khi đua vé.
    Turnstile captcha sẽ tự xuất hiện khi bot click Tiếp tục.

  • Bot không bao giờ tự bấm THANH TOÁN. Bước này luôn cần bạn xác
    nhận để tránh charge nhầm vé.

  • Nếu cần dừng bot giữa chừng: bấm nút "Dừng Hunt" trong popup
    extension.


────────────────────────────────────────────────────────────────────
TROUBLESHOOT (KHẮC PHỤC SỰ CỐ)
────────────────────────────────────────────────────────────────────

❓ Windows Defender chặn SanVePro.exe?
   → Add exclusion: Settings → Update & Security → Windows Security
     → Virus & threat protection → Manage settings → Add exclusion
     → File → chọn SanVePro.exe

❓ Extension không hoạt động sau khi load?
   → Reload extension: chrome://extensions/ → bấm icon Reload trên
     "Săn Vé Pro"

❓ App desktop báo "API chưa kết nối"?
   → Đảm bảo SanVePro.exe đang chạy. Check Task Manager.

❓ Captcha xuất hiện nhưng bot vẫn chạy tiếp / không chờ?
   → Reload tab Ticketbox, sau đó bấm Alt+1 lại.

❓ Reserve thất bại với lỗi "no_captcha_token"?
   → Captcha cache hết hạn (>1h). Click 1 khu để giải captcha mới,
     sau đó bấm Alt+1 lại.

❓ Bot click khu nhưng không có vé sẵn?
   → Đợi đến giờ mở bán + đảm bảo zone target có vé. Check log
     trong app desktop xem chi tiết.
